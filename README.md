## 🧠 核心亮點

1. **依 PM 實務使用頻率排序的 17 種常用圖表**：從 `#1 甘特圖`、`#2 河道圖`、`#3 長條圖`、`#4 瀑布圖` 到 `#17 直方圖`。
2. **所有圖表皆可自訂標題與數據，並一鍵匯出**：支援 **2x 高畫質 PNG 簡報圖檔**與 **SVG 向量檔**匯出，直接貼入 PowerPoint / Keynote / Notion 使用。
3. **10 大 PM 實戰思維與管理工具箱（大人學 / TOC 限制理論 / PMBOK）**：
   1. **TOC 衝突圖（蒸發雲 Evaporating Cloud）** — 拆解共同目標、必要條件與隱藏假設，提出雙贏破局方案
   2. **專案鐵三角與優先級共識矩陣** — 時間 / 範疇 / 成本「一固定、一優化、一調節」開案簽署
   3. **利害關係人權力 × 利益矩陣** — 識別「高權力×低關切」潛在否決地雷與支持度色標
   4. **WBS 工作分解結構圖（100% 法則）** — 以可交付成果（名詞）拆解工作包
   5. **CCPM 關鍵鏈緩衝河道圖（Fever Chart）** — 綠黃紅三色斜率河道即時追蹤進度 vs 緩衝消耗
   6. **RACI 權責分工矩陣（含自動健檢）** — 自動偵測是否違反「唯一當責者 A」原則
   7. **風險機率 × 衝擊矩陣與應對四策** — 5×5 熱區圖搭配規避/減輕/轉嫁/承受對策
   8. **TOC 現況樹與根因分析（CRT）** — 從表面症狀 (UDE) 追查單一核心根因
   9. **PERT 三點科學估時與信心計算機** — 計算期望值與 85% / 95% 準時交付把握工期
   10. **MoSCoW 需求優先級與容量裁剪看板** — 控管 Must Have ≤ 60% 產能，防止範疇蔓延
