## 🌟 目前收錄核心模組：17 種常用數據與專案圖表互動指南

提供 **17 種最常用的數據與專案管理圖表**，每張圖表皆內建**即時可調整的互動參數控制面板**（滑桿、模式切換、視覺偏誤實驗），並詳細整理：
1. **🎯 核心用途 (Purpose)**：解決什麼視覺認知問題？
2. **💼 常見實務場景 (Common Scenarios)**：商業、產品、工程、財務與科研的具體應用。
3. **⚠️ 注意事項與避坑指南 (Caveats & Best Practices)**：如何避免截斷座標軸、分箱誤導、面積錯覺等常見陷阱。

### 📊 17 種常用圖表一覽表

| # | 圖表名稱 | 英文名稱 | 分類 | 可調整互動實驗重點 |
|---|---|---|---|---|
| 1 | **長條圖 / 柱狀圖** | Bar / Column Chart | 比較類 | 垂直/水平切換、排序方式、Y軸起點截斷誤導模擬 |
| 2 | **折線圖** | Line Chart | 趨勢類 | 雜訊波動度、長期斜率、移動平均線 (MA)、平滑插值 |
| 3 | **圓餅圖 / 甜甜圈圖** | Pie / Donut Chart | 佔比與結構類 | 內圈挖空比例、切塊數量 (3~8項擁擠度比較)、凸顯區塊 |
| 4 | **面積圖 / 堆疊面積圖** | Area / Stacked Area | 趨勢類 | 堆疊總量 / 100% 百分比結構 / 重疊模式、填色透明度 |
| 5 | **散佈圖** | Scatter Plot | 關聯與多維度類 | 相關係數強度 ($r$)、樣本數、線性迴歸線、極端離群值拉扯實驗 |
| 6 | **氣泡圖** | Bubble Chart | 關聯與多維度類 | 氣泡面積縮放 ($\sqrt{\text{Value}}$)、四象限分割線、標籤顯示 |
| 7 | **雷達圖 / 蜘蛛網圖** | Radar Chart | 比較類 | 評估維度軸數 (5~8軸)、雙方案疊加對比、填色濃度 |
| 8 | **直方圖** | Histogram | 分佈類 | **分箱數 (Bins 5~25)**、常態/雙峰/右偏分佈切換、平均數 vs 中位數線 |
| 9 | **盒鬚圖 / 箱形圖** | Box Plot | 分佈類 | 四分位距 (IQR) 離散度、$1.5\times\text{IQR}$ 離群點、疊加原始樣本散點 |
| 10 | **熱力圖 / 矩陣圖** | Heatmap | 關聯與多維度類 | 單向漸層 vs 藍白紅雙極色階、對比強化、格內數值開關 |
| 11 | **矩形樹狀圖** | Treemap | 佔比與結構類 | 區塊間距、依分類著色 vs 依漲跌紅綠著色（股市地圖風格） |
| 12 | **漏斗圖** | Funnel Chart | 佔比與結構類 | 各階段留存率滑桿、環比轉化率自動計算與瓶頸視覺化 |
| 13 | **瀑布圖 (增減橋接圖)** | Waterfall Chart | 趨勢類 | 正向貢獻與成本扣除倍率、期初至期末階梯連接虛線 |
| 14 | **桑基圖 / 流向圖** | Sankey Diagram | 關聯與多維度類 | 多節點分流權重、流帶曲率平滑度、流量守恆數值標註 |
| 15 | **子彈圖 / 目標達成圖** | Bullet Chart | 比較類 | 年度目標線位置、實際達成值調整、背景好壞品質區間開關 |
| 16 | **河道圖 / 主題河流圖** | River / Channel & Stream | 趨勢類 | 區間通道河道（均值＋$\pm 1\sigma / \pm 2\sigma$ 波幅）與主題河流圖切換、破岸異常偵測 |
| 17 | **甘特圖 (專案時程圖)** | Gantt Chart | 趨勢類 | 今日基準線 (Today) 移動、要徑任務延誤骨牌效應模擬、前置依賴箭頭 |

## 🧩 未來新增更多 Tool 的擴充方式

本專案採用零建置依賴（Zero-build Vanilla ES + SVG）與模組化架構，部署於 GitHub Pages 即可直接開啟：

```text
Tools-select/
├── index.html            # 工具大廳與互動工作台主頁面
├── css/
│   └── style.css         # 深淺色主題與響應式設計系統
├── data/
│   └── charts-data.js    # 15種圖表的知識庫與控制項定義
└── js/
    ├── registry.js       # 全域多工具註冊表（新增工具只需改這裡！）
    ├── chart-renderer.js # 15種圖表 SVG 即時向量渲染器
    └── app.js            # 視圖切換、決策篩選、隨機抽卡與收藏管理
```

若未來要加入新的工具（例如：統計檢定選擇器、配色實驗室、資料清洗速查器）：
1. 在 `js/registry.js` 的 `window.TOOLS_REGISTRY` 陣列中新增一筆工具描述物件。
2. 將工具邏輯獨立放入 `js/` 與 `data/`，即可在頂部導覽列與「全部工具大廳」無縫切換！
